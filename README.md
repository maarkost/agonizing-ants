# 🏎️ SUV Off-Road Smash!

This repository contains the source code for **SUV Off-Road Smash!**, a fun, single-file JavaScript racing game.

## 🎮 Gameplay

*   **Choose Your SUV:** Select from a variety of 10 different SUVs, each with unique stats for speed and handling.
*   **Pick Your Track:** Race on 4 different tracks: Off-Road, Road, Desert, and Mixed.
*   **Race Against AI:** Compete against 3 other AI-controlled racers.
*   **Take Damage:** Watch out for bumps! Collisions will damage your vehicle, affecting its performance.
*   **Finish the Race:** Complete 3 laps and try to get 1st place!

## 🚀 How to Play

1.  Clone this repository.
2.  Open the `suv_offroad_race.html` file in your web browser.
3.  Select a car and track.
4.  Race!

## ⌨️ Controls

*   **Arrow Keys** or **A/D** to steer.
*   **Up Arrow** or **W** to accelerate.
*   **Down Arrow** or **S** to brake.
*   **Touch controls** are also available on mobile devices.

## 🛠️ Built With

*   HTML5 Canvas
*   JavaScript (ES6)
*   CSS3
